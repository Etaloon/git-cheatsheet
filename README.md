# Шпаргалка по Git 
## Создание репозитория
git init - Создать локальный Git-репозиторий 

## Проверка состояния 
git status - посмотреть текущее состояние репозитория

## Работа с изменениями
git add . - подготовить изменения к коммиту
git commmit -m "Сообщения" - сохранить изменения в коммите

## Работа с ветками 
git branch - посмотреть список веток
git checkout имя_ветки - перети в другую ветку
git checkout -b имя_ветки - создать новую ветку и перейти в неё
git merge имя_ветки  - объединить изменения из другой ветки в текущую

## Работа с GitHub
git push - отправить локальные коммиты на GitHub
git pull - получить изменения из удалённого репозитория
